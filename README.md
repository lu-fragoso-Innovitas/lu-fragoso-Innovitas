### 🚀 Projeto em destaque

<div align="center">

<table>
<tr>
<td width="100%">

#### 🥗 NutriCloud — SaaS multi-tenant de saúde

Plataforma de gestão para nutricionistas e clínicas: agenda, prontuário, anamnese,
antropometria, planos alimentares, diário alimentar, teleconsulta e portal do paciente.

- **API** — `NestJS` · `Drizzle ORM` · **multi-tenant com schema PostgreSQL por clínica**
- **Segurança** — controle de acesso por papel (`CASL`) · isolamento de dados de pacientes · LGPD
- **Async** — filas `Bull` + `Redis` · `WebSockets` para chat e notificações em tempo real
- **Integrações** — Google Agenda · Outlook · Apple Calendar (`CalDAV`) · login social · IA
- **Web** — `React` + `Vite` · `TanStack Query` · `Tailwind` + `Radix UI` · 4 idiomas
