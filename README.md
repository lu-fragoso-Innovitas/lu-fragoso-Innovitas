### 🚀 O que já entreguei

No **NutriCloud**, plataforma SaaS multi-tenant para nutricionistas e clínicas:

- 📅 **Integrações de agenda**: sincronização bidirecional com **Outlook** e **Apple Calendar** (`CalDAV`) e conexão OAuth com o **Google Agenda**
- 🌍 **Internacionalização**: plataforma disponível em **4 idiomas**
- 🔐 **Segurança**: controle de acesso a dados de pacientes, com foco em **LGPD**
